# 家計トラッカー

固定費・サブスク・支払い期限を管理するための、あなた専用の家計簿アプリです。
シンプルな白・黒基調のデザインで、毎月の「支払い予定」と「支払い済み」がひと目でわかります。

- データはこの端末のブラウザ内（localStorage）だけに保存されます。サーバーには送信されません。
- GitHub Pages で公開し、iPhone の Safari から「ホーム画面に追加」することで、アプリのように使えます。

## できること

- 固定費・サブスク・その他支出、収入を「毎月◯日」という形で登録
- 今月の合計収入・支出予定・差引残高をひと目で表示
- 支払い済みの項目はチェックを付けて管理
- 支払期限を過ぎている未払い項目は赤字で警告表示
- 「すべて／期日支払い／固定費／サブスク」でリストを絞り込み表示
- 前月・翌月の記録も左右の矢印で確認可能
- オフラインでも開けるように簡易対応（Service Worker）

## 1. GitHub にアップロードする

1. [github.com](https://github.com) にログインし、右上の「+」→「New repository」で新しいリポジトリを作成します（例：`kakei-tracker`）。Public のままで構いません。
2. このフォルダの中身（`index.html`、`style.css`、`app.js`、`manifest.json`、`sw.js`、`icons` フォルダ）をすべて、作成したリポジトリにアップロードします。
   - GitHub の画面で「Add file」→「Upload files」を選び、ファイル一式をドラッグ＆ドロップするのが簡単です。
   - フォルダごとドラッグすると `icons/` の中身も含めてアップロードされます。
3. 「Commit changes」でアップロードを確定します。

## 2. GitHub Pages で公開する

1. リポジトリの「Settings」タブを開きます。
2. 左側メニューの「Pages」を選びます。
3. 「Build and deployment」の「Source」で **Deploy from a branch** を選択します。
4. 「Branch」を `main`（または `master`）、フォルダを `/ (root)` にして「Save」をクリックします。
5. 数十秒〜数分待つと、ページ上部に
   `https://ユーザー名.github.io/リポジトリ名/`
   という公開URLが表示されます。このURLにアクセスしてアプリが表示されれば成功です。

## 3. iPhone のホーム画面に追加する

1. iPhone の **Safari**（他のブラウザ不可）で、公開されたURLを開きます。
2. 画面下部の共有ボタン（□に↑が付いたアイコン）をタップします。
3. メニューを下にスクロールし、「ホーム画面に追加」をタップします。
4. 名前を確認して「追加」をタップすると、ホーム画面にアイコンが表示されます。

以降はそのアイコンをタップするだけで、アドレスバーのない全画面アプリとして開けます。

## 注意点

- データはこの操作をした **その iPhone・その Safari だけ** に保存されます。他の端末やブラウザとは同期されません。誤ってブラウザの「履歴とWebサイトデータを消去」を行うと記録も消えるのでご注意ください。
- 大切な記録は時々スクリーンショットを撮るか、必要であれば開発者に依頼してエクスポート機能を追加することもできます。
- コードを修正したい場合は、GitHub 上でファイルを編集して「Commit changes」するだけで、公開ページに自動反映されます（数分かかる場合があります）。
